# Политика конфиденциальности неофициального плагина для работы с Яндекс Диском

Действует с 24 ноября 2026 года.

Это неофициальный плагин для работы с Яндекс Диском через API сервиса. Исключительное право на товарный знак «Яндекс» принадлежит ООО «ЯНДЕКС». Название сервиса используется для указания на совместимость плагина. [Условия использования API Яндекс Диска](https://yandex.ru/legal/disk_api/ru/)

Независимый разработчик плагина — Антон Геннадьевич Гребенников. Плагин позволяет работать со своим Диском из локального чата. Эта политика описывает обработку данных самим плагином.

## Вход и права

Вход проходит на странице Яндекс ID. Яндекс получает пароль и выдаёт плагину OAuth-токен. Владелец выбирает чтение либо чтение и запись. Плагин сохраняет токен, идентификатор и имя аккаунта, сведения о правах и сроке входа в системном хранилище учётных данных. В Windows используется Credential Manager, в macOS — Keychain, в Linux — Secret Service. Токен используется для запросов к API Яндекса.

## Что обрабатывается

Для выполнения запроса плагин может получить названия и пути файлов, метаданные, текст, бинарное содержимое, ссылки или сведения о занятом месте. Для отправки или скачивания файла используется адрес передачи, предоставленный соответствующим сервисом. В локальном режиме рабочие файлы передаются через папку Yandex-Disk-Transfer в системных загрузках. При сохранении вложения из чата плагин загружает его по адресу, предоставленному клиентом, и передаёт содержимое на Диск.

Компьютер пользователя обращается к Яндексу напрямую. Результат возвращается в клиент, вызвавший инструмент. При работе в чате OpenAI запрос и возвращённый результат обрабатываются в соответствии с условиями сервиса и настройками аккаунта. Отдельного сервера разработчика для передачи файлов, проектной аналитики и телеметрии в плагине нет. Яндекс обрабатывает данные по правилам своей платформы.

## Локальные копии

Поиск по имени охватывает файлы личного Диска. Для поиска по тексту владелец явно выбирает папки. Индекс содержит извлечённый текст и сведения о файлах. Он хранится на компьютере до перестроения, очистки или выхода. Команда `yandex-disk-plugin index` без указания папок очищает выбор и индекс.

Плагин кэширует прочитанные версии офисных файлов для сохранения правок при конфликте. Версию можно повторно использовать в течение суток. При очередной записи кэш очищается от устаревших версий и ограничивается 128 МиБ. В отдельно настраиваемом режиме личного туннеля на компьютере сохраняются зашифрованные аргументы запроса и краткое описание операции, включая применимые пути, поисковую фразу или адреса правок. Билет действует пять минут. Просроченные записи удаляются при добавлении следующих запросов.

## Управление доступом и удаление

Публичная ссылка создаётся по запросу владельца. Открыть её может каждый, кто её получил. Попросите плагин отозвать ссылку, когда доступ больше не нужен. Файлы, ранее скачанные по ссылке, останутся у получателей.

Команда `yandex-disk-plugin logout` удаляет активную локальную запись входа и папку данных профиля, включая индекс, кэш и очередь запросов. Смена активного аккаунта также очищает прежний профиль плагина. Разрешение приложения можно отозвать в [Яндекс ID](https://id.yandex.ru/profile/access). Файлы на Диске, вручную скачанные копии и историю чата пользователь удаляет отдельно в соответствующем сервисе. При использовании личного туннеля его можно остановить и отключить в клиенте.
