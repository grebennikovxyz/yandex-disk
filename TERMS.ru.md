# Условия использования неофициального плагина для работы с Яндекс Диском

Действует с 24 ноября 2026 года.

Это неофициальный плагин для работы с Яндекс Диском через API сервиса. Исключительное право на товарный знак «Яндекс» принадлежит ООО «ЯНДЕКС». Название сервиса используется для указания на совместимость плагина. [Условия использования API Яндекс Диска](https://yandex.ru/legal/disk_api/ru/)

Независимый разработчик плагина — Антон Геннадьевич Гребенников. Плагин подключает выбранный пользователем Яндекс ID и позволяет читать и изменять доступные этому аккаунту файлы. Плагин распространяется бесплатно и не предлагает покупок.

## Использование

Используйте плагин для файлов и действий, на которые у вас есть разрешение. При первом входе выберите нужный объём прав. Для просмотра и поиска достаточно доступа только на чтение. Проверяйте путь, получателя и режим доступа перед изменениями файлов. Публичная ссылка позволяет любому её получателю открыть опубликованный объект.

Для работы нужны учётная запись Яндекса, поддерживаемый локальный клиент и среда запуска, указанная в инструкции к пакету. Ответы модели и результаты редактирования можно проверить по ссылке на файл. Правка офисного документа создаёт отдельную копию. Операция перемещения в корзину изменяет расположение выбранного объекта на Диске.

Использование Яндекс ID и Яндекс Диска регулируется условиями Яндекса, а использование клиента OpenAI — условиями соответствующего продукта OpenAI. Эти сервисы определяют доступность аккаунта, функции и тарифы. Плагин использует выданные пользователем разрешения.

## Отключение и поддержка

Чтобы прекратить использование, выполните `yandex-disk-plugin logout`, отзовите разрешение в Яндекс ID и отключите плагин в клиенте. Если вы настраивали личный туннель, остановите его. Порядок обработки локальных копий и данных чата описан в политике конфиденциальности плагина. Технические вопросы можно задать в публичном разделе обращений проекта.
