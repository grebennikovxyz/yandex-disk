# Plaugin for Ya-Di — задачи

Неофициальный ИИ-плагин для работы с Яндекс Диском через API сервиса. Исключительное право на товарный знак «Яндекс» принадлежит ООО «ЯНДЕКС».

## Учётные записи, проекты и чаты

- [ ] **Несколько Дисков.** Добавлять учётную запись через Яндекс ID, сохраняя ранее подключённые. Дать владельцу возможность назвать Диски, например «Заказы Pixlpark», «Рабочий» и «Личный». Показывать для каждого имя владельца и права. Сохранить существующее подключение при обновлении.
- [ ] **Диск проекта.** Закреплять профиль за проектом Codex. Показывать выбранный Диск до первой операции. Если доступ к нему отозван, предложить восстановить вход. Проверить на двух одновременно открытых проектах с одноимёнными файлами на разных Дисках.
- [ ] **Выбор в чате.** Дать владельцу возможность спросить «С каким Диском мы работаем?» и выбрать другой из разрешённых проекту. Определить, как клиент передаёт и сохраняет выбор конкретного чата. Агент, промпт и скил в этом чате должны работать с выбранным Диском. Проверить параллельные чаты, изоляцию результатов поиска, кэша и привязку подтверждений к аккаунту.

## Платформы и язык

- [ ] **macOS и Linux.** Проверить чистую установку, запуск из Codex, вход через браузер, чтение и запись через MCP, работу Keychain и Secret Service. Указать, какие способы распространения доступны без регистрации разработчика и где нужна подпись.
- [ ] **Android и iOS.** На каждой платформе проверить два сценария: работа из мобильного чата с MCP на компьютере владельца и запуск MCP на самом устройстве. Выяснить, какие клиенты поддерживают подключение, как работает подтверждение, что происходит в фоне и какие варианты установки доступны без аккаунта разработчика магазина.
- [ ] **Python или Node.js.** Текущая реализация использует Python 3.13. Сравнить её с актуальными Node.js LTS и Current на одном сценарии входа, чтения DOCX и сохранения правки. Сравнить совместимость клиентов, размер установки, системное хранилище ключей и поддержку зависимостей. Решение о переносе принять по результатам проверки на целевых платформах.
