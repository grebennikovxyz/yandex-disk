# Яндекс Диск для Codex и ChatGPT

Один локальный MCP-сервер для личного Диска. Codex и ChatGPT Desktop запускают его по stdio. ChatGPT Web обращается к тому же набору операций через персональный OpenAI Secure MCP Tunnel с локальным подтверждением владельца.

Пользователь входит через Яндекс ID, ищет файлы по имени и содержимому выбранных папок, читает и создаёт документы, меняет адресные элементы офисных файлов и сохраняет результат на Диске. REST API отвечает за файлы и корзину. SQLite FTS5 и офисные библиотеки работают на компьютере пользователя. Публикация и снятие ссылок являются отдельными действиями. Персональные приглашения, совместные комментарии и история сервиса открываются в интерфейсе Яндекса.

Приёмка охватывает изоляцию аккаунтов, отзыв входа, чтение без прав записи, конфликт редактирования, сохранение оформления и режим закрытого доступа. Проверки реальных клиентов отмечаются отдельно от автоматических.
